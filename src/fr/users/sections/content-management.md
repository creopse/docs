# Gestion de contenu

Cette rubrique regroupe tout ce qui concerne le contenu public de votre site : ses informations générales, ses modèles de contenu (services, projets...) et ses pages.

## Informations de base

Nom du site, email, téléphone, adresse, code postal et description — les informations affichées un peu partout sur votre site (Header, Footer, pages de contact...). D'autres onglets voisins permettent de gérer l'identité visuelle (logo, couleurs) et les réseaux sociaux.

![Informations de base](/images/screenshots/fr/dark/basic-information.png#dark-only)

## Modèles de contenu

Un modèle de contenu représente un type de contenu répétitif propre à votre site — par exemple vos services ou vos projets — avec une structure définie (titre, description, image...) et une liste d'entrées. Les onglets **Contenu éditorial / Entrées utilisateur / Données système** permettent de filtrer selon leur origine, et **Ouvrir** donne accès aux entrées d'un modèle pour les créer, modifier ou supprimer.

![Modèles de contenu](/images/screenshots/fr/light/content-models.png#light-only)
![Modèles de contenu](/images/screenshots/fr/dark/content-models.png#dark-only)

## Pages

La liste de gauche affiche toutes les pages du site (recherche, ajout, réorganisation). En sélectionnant une page, vous retrouvez :

- ses sections, dans l'ordre d'affichage, chacune avec une case **Afficher** pour la publier ou la masquer sans la supprimer ;
- un bouton **Données & Paramètres** par section pour en modifier le contenu ;
- **Insérer ou retirer des sections** pour composer la page ;
- **Ouvrir l'éditeur visuel** pour modifier le contenu directement sur le rendu de la page — voir [Éditeur visuel](./visual-editor).
