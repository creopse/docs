# Extensions

Les extensions ajoutent des fonctionnalités supplémentaires à votre site, au-delà de ce qui est fourni par défaut.

![Liste des extensions](/images/screenshots/fr/light/plugins-list.png#light-only)
![Liste des extensions](/images/screenshots/fr/dark/plugins-list.png#dark-only)

## Installer une extension

Le bouton **Téléverser une extension** ouvre une fenêtre où glisser-déposer (ou sélectionner) le fichier `.zip` de l'extension, puis **Valider** pour l'installer.

![Téléversement d'extensions](/images/screenshots/fr/light/plugins-upload.png#light-only)
![Téléversement d'extensions](/images/screenshots/fr/dark/plugins-upload.png#dark-only)

::: warning
N'installez que des extensions provenant d'une source de confiance — une extension a accès à votre site une fois installée.
:::
