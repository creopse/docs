# Médiathèque

La médiathèque centralise toutes les images, vidéos, audios et documents de votre site. Un fichier importé ici peut être réutilisé sur n'importe quelle page sans avoir à le téléverser à nouveau.

![Médiathèque](/images/screenshots/fr/light/media-library.png#light-only)
![Médiathèque](/images/screenshots/fr/dark/media-library.png#dark-only)

## Retrouver un fichier

- Les onglets **Tous / Image / Vidéo / Audio / Document / Autre** filtrent la médiathèque par type de fichier.
- Le filtre **Mois** et le champ **Rechercher** affinent la liste.
- L'onglet **Corbeille** regroupe les fichiers supprimés, encore récupérables.

## Ajouter un fichier

Le bouton **Ajouter** en haut à droite ouvre le téléversement d'un nouveau fichier.

## Actions sur un fichier

Chaque vignette propose quatre actions : voir les informations du fichier, le dupliquer, le modifier (nom, texte alternatif...) et le supprimer.

::: tip
Une case à cocher par fichier (et **Tout sélectionner** en haut de la liste) permet d'appliquer une action à plusieurs fichiers à la fois.
:::
