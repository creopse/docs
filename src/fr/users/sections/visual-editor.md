# Éditeur visuel

L'éditeur visuel permet de modifier le contenu d'une page directement sur son rendu, plutôt que depuis les formulaires de [Gestion de contenu](./content-management). Vos modifications portent uniquement sur le contenu — jamais sur le design des sections.

![Éditeur visuel](/images/screenshots/fr/light/visual-editor.png#light-only)
![Éditeur visuel](/images/screenshots/fr/dark/visual-editor.png#dark-only)

## S'orienter dans l'éditeur

- Le sélecteur en haut permet de changer de page sans quitter l'éditeur.
- Les icônes d'appareil (bureau, ordinateur portable, tablette, mobile) prévisualisent le rendu selon la taille d'écran.
- **Publier** rend vos modifications visibles publiquement ; **Aperçu** ouvre un aperçu sans publier.
- Le panneau de gauche liste les sections de la page — cliquer sur une section (dans la liste ou directement dans l'aperçu) permet de la sélectionner pour la modifier.
- **Insérer ou retirer des sections** ajoute ou retire une section sans quitter l'éditeur.

En bas de l'écran : le nombre de sections sur la page, et l'heure de la dernière sauvegarde.

::: tip
Pensez à publier une fois vos modifications terminées — tant que ce n'est pas fait, seule la version précédente reste visible sur le site public.
:::
