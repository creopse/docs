# Plugins

Cette rubrique gère les extensions installées sur le site — des paquets qui ajoutent des fonctionnalités supplémentaires au-delà de ce que fournit Creopse par défaut.

![Liste des extensions](/images/screenshots/fr/light/plugins-list.png#light-only)
![Liste des extensions](/images/screenshots/fr/dark/plugins-list.png#dark-only)

## Installer une extension

Le bouton **Téléverser une extension** ouvre une fenêtre où glisser-déposer (ou sélectionner) le fichier `.zip` du plugin, puis **Valider** pour l'installer.

![Téléversement d'extensions](/images/screenshots/fr/light/plugins-upload.png#light-only)
![Téléversement d'extensions](/images/screenshots/fr/dark/plugins-upload.png#dark-only)

::: warning
N'installez que des extensions provenant d'une source de confiance — un plugin a accès au site une fois installé.
:::

::: tip Pour les développeurs
Ce que vous téléversez ici est un plugin déjà empaqueté. Pour développer un plugin (classes Laravel générées à l'intérieur du paquet), voir [Développement de plugins](../plugins-development/basics).
:::
