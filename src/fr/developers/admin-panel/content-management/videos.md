# Vidéos

Cette rubrique gère les vidéos du site, qu'elles soient auto-hébergées ou importées depuis YouTube.

![Vidéos](/images/screenshots/fr/light/videos.png#light-only)
![Vidéos](/images/screenshots/fr/dark/videos.png#dark-only)

## Organisation

- Les onglets **Toutes / Auto-hébergé / Youtube** filtrent par source.
- **Categories** classe les vidéos par catégorie.
- **Paramètres** regroupe les réglages généraux de cette rubrique.
- Le champ **Rechercher une vidéo** retrouve une vidéo par nom.

## Actions

**Ajouter une vidéo** ouvre le formulaire d'ajout (fichier auto-hébergé ou URL YouTube selon la source). La case **Tout sélectionner** permet d'appliquer une action à plusieurs vidéos à la fois.
