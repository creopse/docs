# Publicités

Cette rubrique gère les emplacements publicitaires du site.

![Publicités](/images/screenshots/fr/light/ads.png#light-only)
![Publicités](/images/screenshots/fr/dark/ads.png#dark-only)

## Liste des publicités

Chaque publicité affiche son **Aperçu** et son **Identifiant** — l'identifiant est ce qui la relie à un emplacement précis dans le template (voir bouton **Identifiants** pour gérer la liste de ces emplacements). **Ajouter une publicité** ouvre le formulaire de création.

## Formulaire

![Ajouter une publicité](/images/screenshots/fr/light/ad-form.png#light-only)
![Ajouter une publicité](/images/screenshots/fr/dark/ad-form.png#dark-only)

| Champ | Description |
| --- | --- |
| Titre | Traduisible par langue (sélecteur en haut du champ). |
| Description | Traduisible par langue. |
| Contenu | Image de la publicité. |
| Période de diffusion | Date de début / date de fin d'affichage. |
| Identifiant | Emplacement du template auquel cette publicité est associée. |
| Statut | **Caché** ou **Visible**. |
