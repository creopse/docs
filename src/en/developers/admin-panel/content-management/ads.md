# Ads

This section manages the site's advertising placements.

![Ads](/images/screenshots/en/light/ads.png#light-only)
![Ads](/images/screenshots/en/dark/ads.png#dark-only)

## Ad list

Each ad shows its **Preview** and its **Identifier** — the identifier is what ties it to a specific placement in the template (see the **Identifiers** button to manage the list of these placements). **Add ad** opens the creation form.

## Form

![Add ad](/images/screenshots/en/light/ad-form.png#light-only)
![Add ad](/images/screenshots/en/dark/ad-form.png#dark-only)

| Field | Description |
| --- | --- |
| Title | Translatable per language (selector above the field). |
| Description | Translatable per language. |
| Content | The ad's image. |
| Display period | Start date / end date for the ad to run. |
| Identifier | The template placement this ad is associated with. |
| Status | **Hidden** or **Visible**. |
