# Content Management

The **Content Management** section of the admin panel brings together everything related to the site's public content: platform identity, pages, sections, content models, permalinks, menus, newsletter, ads and videos. It's the entry point an administrator uses day to day, independently of the integration work done on the code side (see the [developer documentation](../../development/sections-widgets) for building the templates themselves).

![Content Management](/images/screenshots/en/dark/basic-information.png#dark-only)

## Sections

| Section | Role |
| --- | --- |
| [Platform Identity](./platform-identity) | Basic information, branding (logo, colors) and social networks for the site. |
| [Menu Management](./menus) | Site navigation (header, footer...). |
| [Pages](./pages) | Creating pages and assembling their sections. |
| [Content Models](./content-models) | Reusable data structures (services, projects...) and their entries. |
| [Permalinks](./permalinks) | Association between a piece of content and its public URL. |
| [Newsletter](./newsletter) | Subscribers (emails, numbers) and send campaigns. |
| [Ads](./ads) | Advertising placements on the site. |
| [Videos](./videos) | Video categories and items. |
| [Visual Editor](./visual-editor) | Previewing and editing sections directly on the rendered page. |

::: tip
Each item listed here corresponds to an entry in the side menu visible once inside **Content Management**, on the left of the screen.
:::
