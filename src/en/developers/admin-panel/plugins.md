# Plugins

This section manages the extensions installed on the site — packages that add extra functionality beyond what Creopse provides by default.

![Plugins List](/images/screenshots/en/light/plugins-list.png#light-only)
![Plugins List](/images/screenshots/en/dark/plugins-list.png#dark-only)

## Installing a plugin

The **Upload an plugin** button opens a window where you can drag and drop (or select) the plugin's `.zip` file, then click **Validate** to install it.

![Plugins Upload](/images/screenshots/en/light/plugins-upload.png#light-only)
![Plugins Upload](/images/screenshots/en/dark/plugins-upload.png#dark-only)

::: warning
Only install plugins from a source you trust — a plugin has access to the site once installed.
:::

::: tip For developers
What you upload here is an already-packaged plugin. To develop a plugin (Laravel classes generated inside the package), see [Plugin Development](../plugins-development/basics).
:::
