# Customization

This section (**Settings**) configures the admin interface itself — not to be confused with [platform identity](./content-management/platform-identity), which defines the identity of the **public site** rendered by the templates. Settings are organized into four tabs: **General**, **Appearance**, **Content**, and **Translation**.

![Settings](/images/screenshots/en/light/settings.png#light-only)
![Settings](/images/screenshots/en/dark/settings.png#dark-only)

## Appearance

- **Graphic elements** — logo, icon, and their monochrome versions, used within the admin interface itself.
- **Authentication pages of the administration** — background image and color for the login screens, in both light and dark mode.

The **General**, **Content**, and **Translation** tabs respectively cover global administration settings, options related to content management, and the configuration of available languages.

## Global actions

- **Export** downloads a copy of the current settings.
- **Import** restores settings from a previously exported file.
- **Restore** reverts to the default values.
- **Save** applies the current changes.

::: tip
Export your settings before making a significant change on a production environment — this lets you roll back easily if something goes wrong.
:::
